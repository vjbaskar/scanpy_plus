Overview
========

``scanpy_plus`` provides helper modules that complement Scanpy workflows:

- ``scanpy_plus.pp``: preprocessing helpers (sex assignment, cell-cycle correlation, HVG helpers)
- ``scanpy_plus.tl``: analysis tools (SCVI, GSEA, ranking and mapping utilities)
- ``scanpy_plus.pl``: plotting helpers (UMAP views, ridge plots, split views, Plotly exports)
- ``scanpy_plus.io``: AnnData persistence and notebook metadata helpers
- ``scanpy_plus.data``: curated marker/reference loaders
